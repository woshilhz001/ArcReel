以下为 Action 强化层，叠加在上述官方写作指引之上：官方硬规则（只写可拍摄的主体与环境运动、避开任务类型触发词、镜头运动归 camera_motion 字段）不变，本层只在同一分镜、同一时长内补「写得更细」的策略。分镜按核心事件分两类启用：核心事件本身是打斗、冲撞、追逐、奔跑或激烈情绪爆发时，按「高强度细则」展开；动作幅度小但画面潜力足的场景（拉抽屉、点灯、翻纸、注水、擦拭、摩挲等细部操作）按「低强度丰富化细则」写厚，避免整段只有一个慢动作、画面单一；纯静态对话、无任何动作事件的，按官方指引写即可，两类细则都不启用。
1. 节拍拆解：动作有明确节奏起伏（蓄势→爆发→收束、逼近→定住、揭示→收束）时，可拆成 2–4 拍，每拍配一个时间语义词让动作在时长内有分布；拍数与该分镜的时长和动作复杂度匹配，不是固定 3 段——**平稳单一的运动（缓步走近、持续注视、环境氛围）整段一个节奏即可，不必分时段**；时间语义词按需选用（「开头」「随后」「最后」「全程」均可），不强制三段式，也不要求每段标注秒数。
2. 景别决定可拍范围（一个分镜 = 一个镜头，不跨场景、不切机位、不做多镜头调度）：特写 / 大特写只写镜内可拍的大反应——瞳孔骤缩、身体剧烈一颤、指节攥得发白、发梢带起——不写跳起、奔跑、飞出击出画外；中景写头颈、上半身与手臂；全景 / 远景写全身与位移（跑、扑、跌、转身、摔）。
3. 强物理动词做动作主干（按需选用：扑、甩、掷、砸、抓、扔、踹、蹬、掀、掰、拽、挣、绷、顿、顿住、僵住、踉跄、跪倒、暴起、探、挺、沉、挥臂、攥拳、迈步、甩头）；比喻禁作动作主干，至多一句作动作的后置气氛补充，不替代动作本体。
4. 身体联动与环境交互各至少写一处：联动是一个动作带出全身反应（「他猛地抬头，肩背骤然挺直」）；交互是动作波及环境（门框一震、桌角被带倒、尘埃腾起）。
5. 该分镜有台词时，动作节拍与台词锚定：台词前是蓄势、台词中是强调、台词后是余韵；台词超过三句只锚定最重要的一句。
6. 内容边界：只细化该分镜已定稿的事件，补充的细节（肌肉反应、物件轨迹、环境反应）必须能从分镜内容与原文锚推出；不新增情节、不新增人物、不新增物件，不偏离原著。
低强度丰富化细则（细部操作类分镜，动作本身慢、幅度小）：目标是「慢而丰富」——动作仍按官方低缓基调，但把画面写厚，避免全段只有一句慢动作。
1. 微动多层：一个主动作拆成 2–3 个可观察的微动层——手指的接触方式（捻住、扣住、垫指托起）、物件的轨迹（滑轨走到底、纸角先掀后平、水面缓溢）、身体的微小配合（重心微移、肩背先松、呼吸可见）；每层各占时长的一段，仍保持单一动作主线。**微动只写 2–3 处，禁止逐项罗列身体部位**（如同时写睫毛、鼻尖、嘴唇、肩背、裙摆、发梢、袜口——超过三处的并列微动模型执行率会骤降，只保留最可观察、与剧情最相关的那 2–3 处）。
2. 质感与感官锚定：给动作配可听 / 可触的质感词（金属滑轨的轻响、布面摩擦的涩感、纸页翻动的脆感、烛芯爆亮的噼声），一个动作至少一处，不堆砌。
3. 环境同框：动作之外的环境只写与主动作同框、可互相映照的动态（火光在面颊上流动、尘埃在光柱里浮动、水珠沿杯壁下滑），至多两处，且都从该分镜已定的场景与物件推出。整段（含主动作线与环境线）并行动态线合计不超过 3 条；高频快速变化（内容飞速轮播、高频闪烁、快速切换画面）不写——视频模型渲染高频运动容易出噪点与频闪，改成稳定的光影效果（光斑跳动、光晕流动）。
4. 景别匹配：特写 / 大特写只写指、眼、唇、物件局部；中景写手部与上半身配合；不借丰富化扩出景别外的动作。
5. 内容边界同高强度第 6 条，另加两条：丰富化不得改变人物既定状态（缓步不能写成拖沓跛行、坐姿端正不能写成松垮）；不得新增服装、物件的破损或细节特征（原文没写破洞，就不能写裙角小洞）。
Ambiance_Audio 配合：声音事件与 Action 节拍同步——起、爆、落各对应一处画内音（破空声 → 撞击声 → 余响），逐处与动作对得上即可，不超出画内音边界，不补写动作之外的信息。
