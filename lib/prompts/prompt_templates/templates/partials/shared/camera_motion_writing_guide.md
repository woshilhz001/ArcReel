camera_motion 是每个分镜的主动选择，不是默认回退：从 schema 声明的 14 个运镜值中选最匹配该分镜叙事功能的一个。Static 适合稳定观察，但只是 14 选 1 之一，不要因「拿不准」就选它。
**先分清「谁在动」**：camera_motion 只描述**镜头本身**的运动。人物走向镜头、车辆驶过画面、主体在画面内位移——这些是 action 里的事，镜头可以保持固定机位；只有机位随主体移动（跟拍）、机位逼近/远离主体（推进/拉出）、机位旋转（环绕/平移）时，才选对应的运动值。**主体向镜头走近 ≠ 镜头推进**：人走来而机位不动，选固定机位；机位向静止的人推进，才选推进。
按叙事功能选值（通用，不限场景类型）：
- 情绪逼近 / 细节揭示 / 聚焦（机位向主体逼近）→ 向前推进
- 收束 / 环境展开 / 结尾留白（机位后撤或视野收窄）→ 向后拉出 / 视野收窄
- 机位随行走 / 移动的主体保持同距 → 跟拍（主体走、镜头不动不算跟拍）
- 对峙 / 关系揭示 / 空间环绕（机位绕主体转）→ 环绕
- 并列关系 / 场景横向带过 / 视线引导（机位横移）→ 横向平移
- 权力关系 / 仰视俯视 / 情绪起伏（机位升降）→ 垂直升降
- 紧张 / 冲击 / 失控（手持晃动感）→ 摇晃
- 稳定对话 / 固定机位观察 / 纯氛围 / 主体自行运动而机位不动 → 固定机位
具体用哪个值，以 schema 枚举为准：上面每组对应枚举中语义匹配的那个（如推进类、拉出类、跟拍类），写出枚举原值。
时长匹配：5 秒级分镜优先单次运动（推进 / 平移 / 固定机位）；8 秒级可承载跟拍 / 环绕 / 拉出；12 秒以上可在镜头内做节奏变化（如前段推进逼近、后段定住）。运镜的幅度与速度体现在 action 的描述里，camera_motion 只承载运动类型。
12 秒级分镜的节奏原则：镜头节奏与 action 的节拍同步分布；有明确节奏起伏（逼近→定住、揭示→收束）时才分时段表达，平稳运动（如匀速跟拍）整段一个节奏即可——分几段由该分镜已定稿的动作主线决定，不由时长写死。
幅度与速度的表达手法（只在有叙事意义时写，中等幅度与正常速度不写）：通过主体在画面中占比与位置的变化承载，不写镜头术语——推进感 = 主体由小渐大、细节由模糊变清晰；拉出感 = 主体由大渐小、环境依次入画；跟拍感 = 主体位置稳定、背景持续滑过；环绕感 = 主体角度由正面渐转到侧面 / 背面。幅度与速度随该分镜的情景走：情绪克制用缓 / 小，冲击紧张用快 / 大，从情景出发，不套固定模板。
相邻分镜变化原则：连续 3 个以上分镜不应全用同一运镜；节奏感来自运镜的动-静交替、推-拉交替（静→推→静、跟拍→环绕→拉出）。只有叙事确实要求固定视点（如窥视、审讯、固定机位旁观、主体自行运动）时，才允许连续同值。
硬约束：只从 schema 声明的运镜枚举值中选，一个分镜只选一个值，写出枚举原值（英文）；运镜由 camera_motion 字段承载，action 只写主体与环境的运动，不描述镜头自身（不写「镜头推进 / 镜头跟随」这类话）。
